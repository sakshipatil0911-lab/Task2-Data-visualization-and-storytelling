# Task2-Data-visualization-and-storytelling
Created an interactive Power BI dashboard to analyze sales data and present key business insights using data visualization and storytelling techniques

## 🛠 Tool Used
- Power BI

## 📊 Dashboard Overview
- Sales by Country (Bar Chart)
- Sales Trend over Time (Line Chart)
- Top Customers (Bar Chart)
- Sales by Product Line (Pie Chart)
- Quantity by Product (Column Chart)

## 📈 Key Insights
- USA is the top-performing country
- Classic Cars generate highest revenue
- Sales increased in 2004 and declined in 2005
- Top customers contribute major revenue

## 🎯 Conclusion
The business depends on key regions, products, and customers. Diversification can improve performance.
